Free Links

Free Links is a simple web page that lists free and useful links, for anyone who wants a clean starting point.

It shows an index of free links and only links out. It does not host anything. A daily job adds new suggested links.

Live at free-as-in-links.vercel.app

This app is checked every morning by Control Troll.
